## My path into software engineering

I didn’t start in DevRel — I **built first**, then learned how to help others build.

**2020–2022 · Foundations**  
Harvard CS50 and Alchemy University gave me the fundamentals. I picked up JavaScript, React, and Solidity and started shipping UI and smart-contract integrations.

**2022–2023 · Frontend &amp; product**  
At **Mintyplex**, I led frontend work on Dynastypad — responsive UI wired to smart contracts. That’s where product engineering clicked for me.

**2023–2024 · CTO &amp; community**  
As **CTO at Limitless Network**, I shipped a multi-chain DEX (Solidity + LIFI + React). At **Memoi Africa**, I ran hackathons (800+ devs at Uni of Nairobi), grew a community from 12 to 1,200+, and learned that teaching developers is as rewarding as writing code. **Flagship.FYI (BASE Captain)** deepened my Base ecosystem work.

**2024–2026 · Coinbase**  
What started as **UXR feedback** on Paymaster, OnchainKit, and Base Domains grew into full **DevRel** — CDP advocacy, Base West Africa activations, hackathon support, and technical content for thousands of builders. See highlights below.

Today I’m **open to opportunities**, still building (ccwrapped, MoltScore, agent tooling) and speaking at events across Africa and globally.
